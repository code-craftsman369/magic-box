## 🌟 Overview

Magic Box is a heartfelt web application I created to share the magic of programming with my children. When they enter their names, the app responds with personalized messages accompanied by spectacular firework animations and authentic sound effects.

This project represents more than just code—it's about using technology to create moments of joy and wonder for the people we love most.

---

## ✨ Features

### 🎆 **Dynamic Fireworks Display**
- Realistic firework animations with particle physics
- Authentic "boom" sound effects using Web Audio API
- Multiple coordinated launches for maximum impact

### 💖 **Personalized Messages**
- Custom messages for each family member with unique emojis
- Glowing text animations that capture attention
- Responsive design that works beautifully on all devices

### 📱 **Mobile-Optimized Experience**
- **Add to Home Screen** support for iOS/Android
- Progressive Web App (PWA) capabilities
- Touch-friendly interface perfect for kids

### 🔄 **Smart State Management**
- Works seamlessly with multiple clicks
- No page reload required
- Unique fireworks on every interaction

## 🚀 How to Use

### Option 1: Visit the Live App
Simply open **[Magic Box](https://magic-box-9sz8tkctvvemkx8hyv2hpc.streamlit.app/)** in your browser.

### Option 2: Add to Home Screen (Recommended for Kids!)

**On iPhone/iPad:**
1. Open the app in Safari
2. Tap the Share button (□↑)
3. Scroll down and tap "Add to Home Screen"
4. Tap "Add"
5. Launch from your home screen like a native app!

**On Android:**
1. Open the app in Chrome
2. Tap the three-dot menu
3. Select "Add to Home Screen"
4. Confirm and enjoy!

### Option 3: Run Locally
```bash
# Clone the repository
git clone https://github.com/code-craftsman369/magic-box.git
cd magic-box

# Install dependencies
pip install streamlit

# Run the app
streamlit run magic_box.py
```

Then open your browser to `http://localhost:8501`
